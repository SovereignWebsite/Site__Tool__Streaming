Escolher um desenho

Cada desenho mostra a mesma lista, a sua, de outra maneira. A escolha fica só neste navegador.

  • A prateleira

    Cada título é uma capa numa prateleira. Toque numa capa para ver a ficha.

  • A fila

    O título de hoje num cartão grande e depois os outros pela sua ordem.

  • Fichas

    Cada título é uma ficha, com a sua nota em letra grande.

  • Bilhetes

    Os seus números e gráficos e depois o que já viu, em bilhetes datados.

    Uma lista simples, com um pequeno cartaz ao lado de cada título.

O seu sítio e como o assumir

Esta página é para o dono do Streaming. O sítio é feito de ficheiros estáticos num repositório do GitHub, SovereignWebsite/Site__Tool__Streaming. É servido em https://streaming.tool.sovereignweb.site a partir da pasta site/ do ramo dev.

1. Ligar o GitHub

  1. Crie uma conta no GitHub em github.com/signup, se ainda não tiver.
  2. Envie o seu nome de utilizador do GitHub a quem fez este sítio. Recebe dois convites: um para o repositório, com acesso de escrita (push), e outro para entrar na organização SovereignWebsite como membro. Ser membro não lhe dá acesso a mais nada; serve para o seu próprio Claude poder trabalhar com o seu repositório.
  3. Aceite o convite para o repositório: com a sessão iniciada no GitHub, abra o repositório e prima View invitation na faixa de aviso, ou use a ligação do email.
  4. Aceite o convite para a organização em github.com/orgs/SovereignWebsite/invitation ("Join SovereignWebsite"). Use este endereço: a ligação do email pode não mostrar o botão.
  5. Se usa o Claude, abra as definições do GitHub e prima Check again junto a SovereignWebsite. Enquanto não for membro, aparece "Needs reconnecting".

2. Fazer a primeira alteração

  1. Abra a pasta do sítio no ramo dev e escolha a página a alterar (a página inicial é site/index.html).
  2. Prima o lápis, edite e depois Commit changes no ramo dev.
  3. O fluxo de trabalho Pages publica a alteração e o sítio atualiza-se em um ou dois minutos. O ramo main está bloqueado; tudo passa pelo dev.

Ou deixe o seu próprio agente de IA fazer a alteração: veja Usar com a sua IA.

3. Pedir mais uma ronda

Abra um pedido (issue) em https://github.com/SovereignWebsite/Site__Tool__Streaming/issues/new a dizer o que gostaria de mudar, ou fale com quem fez o sítio. Os agentes do sítio trabalham a partir do repositório, por isso o pedido fica registado.

4. É seu

Os ficheiros, o historial e o endereço estão num repositório que controla. Pode movê-lo para qualquer lado, em qualquer altura: é HTML simples, sem código de servidor, sem cookies e sem rastreio.
